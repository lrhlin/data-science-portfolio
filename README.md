# Data Science Portfolio

This repository contains code and supporting materials for selected projects in my data science portfolio.

The primary project narratives, summaries, and results are documented on my Notion portfolio: 
https://www.notion.so/Data-Project-Portfolio-2cb4ea2be4bf80668930d6e35f0c41a7?source=copy_link

## Projects

### Credit Limit Policy & Default Risk
Causal analysis of a credit policy decision using matching, IPW, and doubly robust estimation.
→ `credit-limit-causal/`

### Nursing Home Staffing & Quality (Japan)
Observational analysis of staffing levels, turnover, and care quality using national survey and administrative data.
→ `nursing-home-quality/`

### Supermarket Sales Drivers (Favorita)
Large-scale retail analytics project identifying key drivers of sales across stores, categories, and time.
→ `favorita-sales/`

### Targeted Sentiment Extraction from Tweets
NLP project focused on extracting sentiment-relevant text spans from short, noisy tweets.
→ `tweet-sentiment-nlp/`

## Notes
Some datasets are omitted or anonymized due to licensing or privacy constraints.
